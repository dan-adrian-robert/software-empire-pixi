

# Difficulty Formula

```text
Common Project   = Team Output × 1.2
Uncommon Project = Team Output × 1.5
Rare Project     = Team Output × 2.0
```

Expected durations:

| Type | Expected Duration |
|---|---|
| Common | 1.2 days |
| Uncommon | 1.5 days |
| Rare | 2.0 days |

# Design Notes

## Why This Works

As the player's company grows:
- Team throughput scales naturally
- Project sizes increase proportionally
- Difficulty remains predictable
- Progression pacing stays stable

This allows project generation to remain:
- Consistent
- Easy to balance
- Easy to tune later with modifiers

---

# Recommended Usage

Use:
- Common projects as filler / reliable income
- Uncommon projects as standard contracts
- Rare projects as high-pressure opportunities

Rare projects should feel:
```text
"We can finish this if we optimize properly."
```

NOT:
```text
"This project is impossible."
```

# Software Empire Raw Team Output Difficulty Table

This table represents project difficulty scaling based only on the **raw SP/day output of the entire team**.

The calculations intentionally ignore:
- Productivity modifiers
- Stress
- Weather
- Office bonuses
- Synergy
- Project manager bonuses

The purpose of this table is to:
- Generate balanced projects
- Scale contracts with company growth
- Estimate expected completion durations
- Create predictable economic pacing
